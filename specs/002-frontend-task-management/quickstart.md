# クイックスタート: フロントエンド タスク基本管理

## 前提

- backend API は SCRUM-6 の契約で起動できる状態にする。
- frontend は `frontend/` 配下で操作する。
- API 接続先は `NEXT_PUBLIC_API_BASE_URL` で指定する。

## 環境変数

`frontend/.env.local` に次を設定する。

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8080
```

## 確認コマンド

```bash
cd frontend
npx tsc --version
npm run lint
npm run build
npm run dev
```

`npx tsc --version` は TypeScript 6 系であることを確認する。

開発サーバー起動後、ブラウザで `http://localhost:3000` を開く。

## 手動受け入れシナリオ

### 1. userId と一覧

1. userId を入力または既定値で確認する。
2. 一覧が loading 状態を経て表示される。
3. 現在の userId に紐づくタスクのみが表示される。
4. タスクが0件の場合、空の一覧表示と登録導線が見える。

### 2. 新規登録

1. 新規登録操作を開く。
2. デスクトップでは右ドロワー、スマホでは全画面モーダルが表示される。
3. タイトル、説明、ステータスを入力する。
4. 登録すると成功通知が表示され、一覧に新しいタスクが反映される。
5. タイトル未入力では送信前に入力欄付近へエラーが表示される。

### 3. 詳細

1. 一覧のタスクを選択する。
2. TaskOverlay にタイトル、説明、ステータスが表示される。
3. TaskOverlay を閉じると一覧へ戻る。

### 4. 編集

1. 詳細から編集へ進む。
2. タイトル、説明、ステータスを変更して保存する。
3. 成功通知が表示され、一覧と詳細に変更内容が反映される。
4. タイトル未入力では送信前に入力欄付近へエラーが表示される。

### 5. 削除

1. 詳細から削除を選択する。
2. 削除確認が表示される。
3. キャンセルするとタスクは一覧に残る。
4. 確認すると成功通知が表示され、タスクは一覧から消える。

### 6. エラー

1. backend 停止時または不正な taskId で操作する。
2. ユーザー向けエラーメッセージが表示される。
3. 画面はクラッシュせず、再試行または別操作を続けられる。

## Jira サブタスク運用

- SCRUM-25 は `feature/sub/SCRUM-25` から作業し、完了時に `feature/SCRUM-7` へ PR を作成する。
- SCRUM-26 は `feature/sub/SCRUM-26` から作業し、完了時に `feature/SCRUM-7` へ PR を作成する。
- 後続の画面実装サブタスクも同じく `feature/sub/SCRUM-x` から親ブランチへ PR を作成する。
